# 🤝 Contributing to Memory Byte Viewer  

Thank you for your interest in contributing!  
This project welcomes developers, students, security researchers, and reverse-engineering enthusiasts who want to improve the tool and help it grow.

Your contributions — whether bug fixes, features, or documentation — make this project stronger.


## 🧭 How to Contribute  

### 1️⃣ Fork the Repository  
Click the **Fork** button on GitHub to create your own copy.

### 2️⃣ Clone Your Fork  
```bash
git clone https://github.com/<your-username>/MemoryByteViewer.git
cd MemoryByteViewer
```

### 3️⃣ Create a New Branch  
```bash
git checkout -b feature/your-feature-name
```

### 4️⃣ Make Your Changes  
- Keep code clean and modular  
- Comment important logic  
- Avoid unnecessary dependencies  
- Test your changes before committing  

### 5️⃣ Commit Your Work  
```bash
git commit -m "Add: description of your feature or fix"
```

### 6️⃣ Push to Your Branch  
```bash
git push origin feature/your-feature-name
```

### 7️⃣ Open a Pull Request  
Go to your fork on GitHub → click **Compare & Pull Request** → submit it.

I will review it as soon as possible!

---

## 📌 Coding Guidelines  

- Follow **PEP8** for Python style  
- Use clear variable/function names  
- Avoid deeply nested logic when possible  
- Keep UI code and logic separate when feasible  
- Provide meaningful commit messages

Want to help but not sure where to start?

## 🐞 Reporting Issues  

If you find a bug, please create an **Issue** with:

- Clear and descriptive title  
- Steps to reproduce  
- Expected vs actual behavior  
- Screenshots or error logs (if possible)  
- System details (Windows version, Python version, etc.)
